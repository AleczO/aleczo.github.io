Numerical Analysis - Differentiation



Taylor Series with Remainder

$$ f(x) = f(a) + f'(a)(x - a) + \frac{1}{2}f''(a)(x - a)^2 + \cdots + \frac{1}{n!}f^{(n)}(a)(x - a)^n + R_n(x) $$
$$ R_n(x) = \frac{1}{n!}\int_{a}^n (x-t)^n f^{(n+1)}(t)dt $$ $$ = \frac{1}{(n+1)!}f^{(n+1)}(c)(x - a)^{n+1} $$ \( a < c < x \)

First-Order Derivative Formulas



Forward Difference Formula


from Taylor series with remainder $$ f(x + h) = f(x) + hf'(x) + \frac{h^2}{2!} f''(c) $$ $$ f(x + h) - f(x) = hf'(x) + \frac{h^2}{2} f''(c) $$ $$ \frac{f(x + h) - f(x)}{h} - \frac{h}{2} f''(c) = f'(x) $$

\(x < c < x + h \)

$$ f'(x) \approx \frac{f(x + h) - f(x)}{h} $$ 
double FD(std::function<double(double)> f, double x, double h){
    return (f(x + h) - f(x)) / h;
}


Central Difference Formula


from Taylor series with remainder

$$ f(x + h) = f(x) + hf'(x) + \frac{h^2}{2!} f''(x) + \frac{h^3}{3!} f'''(c_1) $$

\( x < c_1 < x + h \)


$$ f(x - h) = f(x) - hf'(x) + \frac{h^2}{2!} f''(x) - \frac{h^3}{3!} f'''(c_2) $$

\(x - h < c_2 < x \)



$$ f(x + h) - f(x - h) = 2hf'(x) + \frac{h^3}{6} (f'''(c_1) + f'''(c_2)) $$ $$ \frac{f(x + h) - f(x - h)}{2h} - \frac{h^2}{6}f'''(c) = f'(x) $$

\(x - h < c < x + h \)


$$ f'(x) \approx \frac{f(x + h) - f(x - h)}{2h} $$ 
double CD(std::function<double(double)> f, double x, double h){
    return (f(x + h) - f(x - h)) / (2 * h);
}



Second-Order Derivative Formulas



Three-Point Centered-Difference Formula


$$ f(x + h) = f(x) + hf'(x) + \frac{h^2}{2!} f''(x) + \frac{h^3}{3!} f'''(x) + \frac{h^4}{4!} f^{(4)}(c_1) $$

\( x < c_1 < x + h \)


$$ f(x - h) = f(x) - hf'(x) + \frac{h^2}{2!} f''(x) - \frac{h^3}{3!} f'''(x) + \frac{h^4}{4!} f^{(4)}(c_2) $$

\(x - h < c_2 < x \)



$$ f(x + h) + f(x - h) = 2f(x) + 2\frac{h^2}{2!} f''(x) + 2\frac{h^4}{4!} f^{(4)}(c) $$ $$ f(x + h) - 2f(x) + f(x - h) = h^2 f''(x) + \frac{h^4}{12} f^{(4)}(c) $$ $$ \frac{f(x + h) - 2f(x) + f(x - h)}{h^2} = f''(x) + \frac{h^2}{12} f^{(4)}(c) $$ $$ \frac{f(x + h) - 2f(x) + f(x - h)}{h^2} - \frac{h^2}{12} f^{(4)}(c) = f''(x) $$

\(x - h < c < x + h \)


$$ f''(x) \approx \frac{f(x - h) - 2f(x) + f(x + h)}{h^2} $$ 
double CDSO(std::function<double(double)> f, double x, double h){
    return (f(x + h) - 2 * f(x) + f(x + h)) / (h * h);
}

Five-Point Centered-Difference Formula

$$ f(x + h) + f(x - h) = 2f(x) + \frac{2}{2!}h^2 f''(x) + \frac{2}{4!}h^4 f^{(4)}(x) + \frac{2}{6!}h^6f^{(6)}(c_1) $$ $$ f(x + h) - 2f(x) + f(x - h) = \frac{2}{2!}h^2 f''(x) + \frac{2}{4!}h^4 f^{(4)}(x) + \frac{2}{6!}h^6f^{(6)}(c_1) $$

\( x - h < c_1 < x + h \)

$$ f(x + 2h) + f(x - 2h) = 2f(x) + 2\frac{(2h)^2}{2!} f''(x) + 2\frac{(2h)^4}{4!} f^{(4)}(x) + 2\frac{(2h)^6}{6!}f^{(6)}(c_2) $$ $$ f(x + 2h) + f(x - 2h) = 2f(x) + \frac{2^3}{2!} h^2 f''(x) + \frac{2^5}{4!} h^4 f^{(4)}(x) + \frac{2^7}{6!} h^6 f^{(6)}(c_2) $$ $$ f(x + 2h) - 2f(x) + f(x - 2h) = \frac{2^3}{2!} h^2 f''(x) + \frac{2^5}{4!} h^4 f^{(4)}(x) + \frac{2^7}{6!} h^6 f^{(6)}(c_2) $$

\( x - 2h < c_2 < x + 2h \)





$$ 16f(x + h) - 32f(x) + 16f(x - h) = \frac{2^4}{2!}h^2 f''(x) + \frac{2^5}{4!}h^4 f^{(4)}(x) + \frac{2^5}{6!}h^6f^{(6)}(c_1) $$ $$ f(x + 2h) - 2f(x) + f(x - 2h) = \frac{2^3}{2!} h^2 f''(x) + \frac{2^5}{4!} h^4 f^{(4)}(x) + \frac{2^7}{6!} h^6 f^{(6)}(c_2) $$

$$ - f(x + 2h) + 16f(x + h) - 30f(x) + 16f(x - h) -f(x - 2h) = 12 h^2 f''(x) + h^6(\frac{2^5}{6!}f^{(6)}(c_1) - \frac{2^7}{6!}f^{(6)}(c_2)) $$

$$ \frac{- f(x + 2h) + 16f(x + h) - 30f(x) + 16f(x - h) -f(x - 2h)}{12h^2} = f''(x) - \frac{1}{90}h^4f^{(6)}(c) $$ $$ \frac{- f(x + 2h) + 16f(x + h) - 30f(x) + 16f(x - h) - f(x - 2h)}{12h^2} + \frac{1}{90}h^4f^{(6)}(c) = f''(x) $$

\( x - 2h < c < x + 2h \)



$$ f''(x) \approx \frac{- f(x + 2h) + 16f(x + h) - 30f(x) + 16f(x - h) - f(x - 2h)}{12h^2} $$ 
double FPCDSO(std::function f, double x, double h){
    return (-f(x + 2*h) + 16 * f(x + h) - 30 * f(x) + 16 * f(x - h) - f(x - 2*h)) / (12 * h * h);
}
