The Leaky Integrator Model



Introduction

The neuron's membrane has the property of accumulating electrical charges under current. Accumulated electrical charges escapes with time. We can thus see the neuron's membrane as a "leaky" capacitor.


To derive our model, we first need to mathematically describe the capacitor. Using capacitor i-v equation

\[ C_m \frac{dV(t)}{dt} = I(t) \]

Where $C_m$ is the capacitance of membrane, $V(t)$ is membrane potential and $I(t)$ is current across the membrane.

From previous observations, we can rewrite the current as the sum of leak current $I_L(t)$ and additional current source $I_x(t)$

\[ I(t) = I_L(t) + I_x (t)\]

Leak current is defined as

\[I_L(t) = -g_L(V(t) - E_L) \]

Where $g_L$ is leak conductance and $E_L$ is resting potential of membrane.


Now from equation of capacitor

\[ C_m \frac{dV(t)}{dt} = I(t) \] \[ C_m \frac{dV(t)}{dt} = I_L(t) + I_x(t) \] \[ C_m \frac{dV(t)}{dt} = -g_L(V(t) - E_L) + I_x(t) \]

\[ C_m \frac{dV}{dt} = -g_L(V - E_L) + I_x \]

dividing by $g_L$

\[ \tau_m \frac{dV}{dt} = -(V - E_L) + \frac{I_x}{g_L} \]

where $\tau_m = \frac{C_m}{g_L}$

You can also find the equation

\[ \tau_m \frac{dV}{dt} = -(V - E_L) + I_x \]

where $\frac{I_x}{g_L} \rightarrow I_x$




Discretization and Euler Method Simulation


To simulate a model, for example, in MATLAB or Python, we first need to transform it from a continuous form to a discretized one.

\[ \tau_m \frac{\Delta V}{\Delta t} = -(V_n - E_L) + \frac{I_n}{g_L} \]

where $V_n = V \cdot (n \Delta t)$, $I_n = I \cdot (n \Delta t)$



\[ \begin{aligned} V_{n + 1} &= V_n + \Delta V_n \\ \Delta V_n &= \frac{\Delta t}{\tau_m} \bigg( -(V_n - E_L) + \frac{I_n}{g_L} \bigg) \end{aligned} \]
now we can use python to simulate model 
V0 = -70
V_Thr = 64
E_L = -72
g_L = 4
tau_m = 15

dt = 0.1
T = np.arange(0, 400, dt)
N = T.size


V = np.zeros(N)
V[0] = V0

I = 400.0 * np.ones(N)

for t in range(N - 1):
    if t > 200 * (1 / dt):
        I[t] = 0
    
    dV = (dt / tau_m) * (-( V[t] - E_L) + I[t] / g_L)
    V[t + 1] = V[t] + dV

If we run code, we can see that first our capacitor is being charged to a specified level, and after an external current is turned off, the leakage starts.
