Transformer Architecture Deep Dive

This note explores the core mathematical foundations of the self-attention mechanism, breaking down how queries, keys, and values interact to model sequences.

1. The Self-Attention Mechanism

The fundamental building block of the Transformer is scaled dot-product attention. Instead of processing tokens sequentially, it computes attention scores across the entire sequence simultaneously.

The matrix of outputs is computed as:

$$ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V $$

Where \( Q \), \( K \), and \( V \) represent the Query, Key, and Value matrices respectively. The scaling factor \( \frac{1}{\sqrt{d_k}} \) is crucial because it prevents the dot products from growing too large in magnitude, which would push the softmax function into regions with extremely small gradients.

2. Implementation Details

Below is a conceptual snippet showing how one might implement a basic self-attention block in Python using PyTorch. Notice the use of torch.matmul for the dot products. 

import torch
import torch.nn.functional as F
import math

def scaled_dot_product_attention(query, key, value):
    d_k = query.size(-1)
    scores = torch.matmul(query, key.transpose(-2, -1)) / math.sqrt(d_k)
    p_attn = F.softmax(scores, dim=-1)
    
    return torch.matmul(p_attn, value), p_attn
Note: In practice, Multi-Head Attention applies this operation in parallel across different projected versions of the queries, keys, and values.
